## Monte Carlo Simulation – Yearly Strategy Stability & Risk Modeling
Author: Jnandeep Dev Sarma

Contact: jnandeepdevsarma@gmail.com

# Project Summary

This project implements a portfolio-safe Monte Carlo engine for analyzing yearly trading performance using only statistical inputs (win-rate, average return per trade, and trade frequency).  
It does **not** contain any proprietary strategy logic — all simulations use synthetic, illustrative data.

# Overview

Monte Carlo simulations help traders understand:
- Expected yearly performance  
- Best-case and worst-case outcomes  
- Probability of ruin  
- Max-drawdown distribution  
- Percentile equity paths (P10 / P50 / P90)  

This engine generates thousands of synthetic equity curves using simple statistical inputs rather than revealing actual strategy code.

# Key Features

- Parameter-driven Monte Carlo engine  
- Supports parametric (normal) and bootstrap sampling  
- Generates:
  - Synthetic equity curves  
  - Final equity distribution  
  - Max drawdown distribution  
  - Probability-of-ruin estimates  
- Streamlit UI for interactive simulation  
- Fake example dataset included  
- All values and charts shown here are **not real strategy outputs**
